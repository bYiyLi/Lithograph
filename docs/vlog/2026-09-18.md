### Decisions

- OpenAICompatible 作为独立 SQLite loadable extension / `EmbeddingProviderV1` reference implementation，注册名固定 `openai-compatible`，不依赖 `lithograph-core`，同一 connection 的一个 registration 可以服务多个不同 endpoint/config。
- 所有 Provider 配置统一进入 versioned `providerConfig`，不再有 extension-load 环境变量作为隐藏配置来源；完整字段为 `base_url`、`api_key`、`api_key_env`、`model`、`send_dimensions`、`encoding_format`、`user`、`organization`、`project`、`headers`、`timeout_ms`、`max_retries`、`batch_size`、`semantic_identity`。`dimensions` 继续由 Semantic Index 顶层 contract 拥有，`input` 来自每次 exact String batch。
- Lithograph 不过滤 secret：显式 `api_key` 或 secret custom header 会按原值进入 versioned Schema/history/SHOW/backup；`api_key_env` 只保存环境变量名，request-time 读取实际 value。
- Auth precedence 固定为 custom `Authorization` > `api_key` > `api_key_env` > no Authorization；organization/project 映射 OpenAI headers，custom headers 最后按大小写不敏感语义覆盖 generated headers。
- 支持 OpenAI Embeddings 当前 `float` / `base64` encoding、可选 dimensions request、`user`、Bearer、organization/project 与 custom headers；Managed Semantic 只接受 String source，因此不增加 token-array input surface。
- `send_dimensions=false` 用于不接受 OpenAI optional dimensions field 的模型；无论是否发送 request field，response 都必须匹配 Semantic Index 顶层 dimensions。
- Batch 只按 item count（1–2048）分批，不引入 tokenizer、不自动 truncate/chunk；remote endpoint 负责模型/token-limit error。Provider 支持 bounded timeout/retry/Retry-After/cancel，并严格校验 response count/index/dimension/finite values。
- Cache v1 保守使用完整 canonical `providerConfig` + implementation ABI semantic identity + dimensions；任何 config 变化都可以分裂 cache space。`semantic_identity` 是调用方用于 endpoint/model mapping 漂移的显式 versioned salt；同名 `api_key_env` 的 secret value 若改变语义路由，调用方也必须改变该 salt。
