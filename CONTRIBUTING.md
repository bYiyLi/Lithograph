# Contributing to Lithograph

Lithograph welcomes bug reports, design feedback, compatibility findings, and other discussion through GitHub Issues.

The project is dual-licensed under AGPL-3.0 and separate commercial licenses. To preserve the project's ability to offer both licensing paths, external code contributions are not currently accepted until a contributor licensing policy is published.

Please do not submit pull requests containing code or documentation changes yet. This policy will be revisited before external code contributions are opened.
