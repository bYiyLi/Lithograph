# Lithograph v0.1.0

Lithograph v0.1.0 是首个公开版本：一个运行在标准 SQLite 上的版本化 Property Graph 数据库引擎，以 loadable extension 交付，无需独立 Server。

## 主要能力

- Property Graph：Node、Relationship、Label、Relationship Type 与 Property。
- 冻结的 Cypher 25 compatibility profile；3,777/3,777 applicable inherited openCypher TCK 通过。
- immutable Commit DAG、Branch、Tag、Commit Data、Time-travel、Diff/Patch、Merge、Rebase、Squash、Reset、Revert 与 GC。
- versioned Graph Type、Constraint、Standard Index、Full-text Index、Vector Index、`SEARCH` 与 `LOAD CSV`。
- storage format 3、persistent Standard Index、邻接 keyset、query-owned resolved state/read guard 与增量 index overlay。

## Runtime

- 最低 SQLite：3.45.0。
- Release gate 同时验证 SQLite 3.53.4。
- `.load` 注册 Lithograph API；`SELECT lithograph_init();` 才会初始化或迁移当前 SQLite database。

## 规模与质量证据

- 10M Node / 100M Relationship release workload。
- 1M×128、100K×1536 Vector 与 1M Full-text corpus。
- 10,000-conflict Merge Session。
- 1/4/8 readers + 1 writer 各 30 分钟 mixed stress。
- repository-wide quality/coverage、真实 SQLite load/ABI/interop 与六平台 hosted Release Matrix 均通过。

## 升级与兼容性

v0.1.0 是 pre-1.0 release。后续 minor release 仍可能调整公开 API、ABI 或 storage compatibility contract。升级已有 database 前应保留完整备份；storage format 3 没有自动 downgrade。

旧 26 GiB format 2 大库的完整 integrity migration 在现有测试窗口中曾超过 1 小时，因此 v0.1.0 不承诺大型旧库迁移的低延迟。
